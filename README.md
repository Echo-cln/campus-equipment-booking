# 物尽其用

“物尽其用”是面向校园共享设备的预约与使用登记前端。页面使用原生 HTML、CSS 和 JavaScript，数据直接读取课程提供的模拟服务端，不在浏览器中编造设备、预约或统计记录。

## 功能

- 浏览、按名称或编号搜索并分页查看设备；设备信息和累计使用次数来自服务端。
- 选择设备与月份查看预约日期，按日期查看已登记设备或由设备目录与当日记录计算出的空闲设备。
- 查看单台设备的登记历史，按登记时间分组。
- 选择一件设备并提交最多五个使用日期；由服务端判断冲突，页面显示冲突日期。
- 切换使用者和管理员界面；管理员可勾选多台设备对比服务端累计使用次数。
- 在线读取成功的数据会缓存在浏览器；服务端不可达时显示缓存并进入只读状态，禁用预约。

## 运行

1. 在 Windows 上解压课程提供的“模拟服务端 v0.1”，运行 `模拟服务端.exe`。服务默认监听 `http://127.0.0.1:12345`。服务端使用的 `Device.txt` 和 `Record.txt` 留在其程序目录中。
2. 用现代浏览器打开 `index.html`。如浏览器不允许本地文件跨域访问本机服务，请按课程环境允许的方式托管静态页面，并确认服务端允许该页面来源跨域请求；本项目没有另建代理服务器。
3. 服务地址可在 `config.js` 的 `apiBaseUrl` 中修改，默认值为 `http://127.0.0.1:12345`。

模拟服务端是 Windows/.NET Framework 可执行文件，本项目本身是静态前端，不能在 Linux、GitHub Pages 或一般静态托管环境中代替该服务端运行。跨域响应策略也取决于教师提供的服务端配置。

## 接口映射

| 页面功能 | 教师服务接口 | 前端处理 |
| --- | --- | --- |
| 连通性检查与设备目录 | `GET /getDevices?page=1&pageSize=10000` | 读取 `No`、`Name`、`UseCount`；前端搜索和分页 |
| 设备可选编号 | `GET /getDeviceNo` | 兼容服务端返回的 XML 字符串数组 |
| 设备月历 | `GET /getRecordByNo?no=...&start=...&end=...` | 将 `UseDate` 转为日历占用日期 |
| 当日已登记 | `GET /getRecordByDate?date=...&page=1&pageSize=10000` | 记录与设备目录关联后分页显示 |
| 当日空闲设备 | 上述当日记录 + `/getDeviceNo` | 用设备编号集合扣除当日已有登记的编号 |
| 单设备登记历史 | `GET /getRecordByNo?no=...&start=2000-1-1&end=2100-12-31` | 依据 `RegTime` 分组，依据 `UseDate` 展示使用日期 |
| 管理员使用次数对比 | 设备目录中的 `UseCount` | 按多选设备绘制累计次数对比；接口未提供按时间段统计 |
| 提交预约 | `GET /regDevice?No=...&UseDates=日期,日期` | 解析服务端返回的冲突日期；预约用途说明不提交，因为该接口不接收用途字段 |

服务端字段中的 `RegTime`、`UseDate` 使用 .NET `/Date(milliseconds)/` 格式，前端会按时间戳携带的时区偏移转换为登记日期和时间。设备与记录接口不提供设备分类、使用者姓名、用途、审批状态或预约分页总数；页面不伪造这些字段。角色切换用于展示不同工作界面，不是服务端身份认证或权限控制。

## 离线缓存

浏览器仅缓存成功读取的服务端响应。无法连接服务端时使用对应缓存作为只读内容；首次访问时尚无缓存则显示连接错误和空状态。预约请求不会写入本地缓存，也不会在离线时排队提交。

## 项目文件

- `index.html`：页面结构、日历、设备目录、使用登记和预约表单
- `styles.css`：暖亚麻、海玻璃、港湾蓝与蜂蜜色的响应式视觉样式
- `app.js`：页面状态、交互、列表渲染和表单逻辑
- `api.js`：教师模拟服务端接口适配、日期格式转换和只读缓存
- `config.js`：服务端地址、超时和列表页大小
- `assets/favicon.svg`：本地图标
