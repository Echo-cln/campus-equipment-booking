# 物尽其用

校园共享设备预约与使用登记。

这是一个无构建依赖的静态前端页面，使用原生 HTML、CSS 和 JavaScript。设备、日历、使用登记、预约和统计数据均应来自课程提供的模拟服务端；页面没有内置业务演示数据，也不包含自建服务端。

## 页面功能

- 使用者视图：设备分类、搜索和分页；选择设备后查看日历占用情况与该设备预约历史；选择日期后分页查看当日已使用或空闲设备；选择设备和最多五个日期后提交预约。
- 管理员视图：切换角色后选择设备，并按周期查看服务端返回的使用次数对比。
- 服务端状态：在线时允许读写；网络中断时展示浏览器上次成功读取的缓存，并禁止提交预约。
- 所有图标、插画、样式和脚本均为本地资源，不依赖远程字体、图片或 CDN。

## 运行与配置

页面由 index.html 直接加载。将 config.js 中的 apiBaseUrl 配置为课程模拟服务端地址；若页面和服务端使用同一来源，可留空。

服务端接口集中定义在 api.js 的 routes 对象中。当前页面的接口调用采用常见 REST 路径约定，响应字段兼容 data、items、list 等常见包装形式。提交或演示前，必须依据课程发放的《模拟服务端使用说明》核对并调整路径、查询参数、预约请求体和字段映射。不得用前端静态数据替代模拟服务端。

## 文件

- index.html：页面结构和预约表单
- styles.css：暖亚麻、海玻璃、港湾蓝与蜂蜜色的响应式样式
- app.js：设备、日历、登记、预约、角色切换和统计交互
- api.js：模拟服务端请求与只读缓存
- config.js：模拟服务端连接配置
- assets/favicon.svg：本地站点图标

## 当前接口约定

| 用途 | 方法 | 当前路径约定 |
| --- | --- | --- |
| 连通性检查 | GET | /health |
| 设备列表 | GET | /api/devices |
| 月历占用日期 | GET | /api/calendar |
| 当日使用情况 | GET | /api/usage |
| 单设备预约历史 | GET | /api/devices/{id}/history |
| 设备使用统计 | GET | /api/admin/statistics |
| 提交预约 | POST | /api/reservations |

课程模拟服务端的接口说明未包含在目前可访问的仓库文件中，因此上述路径与预约字段仍需按教师提供的接口文档核对。页面不会在连接失败时伪造设备或预约记录。
