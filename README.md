# 物尽其用

“物尽其用”是一个校园共享设备预约与使用登记前端。项目使用原生 HTML、CSS 和 JavaScript，连接课程提供的模拟服务端读取设备和登记数据。

## 功能

- 设备一览支持名称或编号搜索、分页和设备历史记录查看。
- 选择设备后，可按月份、周或日查看登记日期；日历支持箭头翻月，也支持直接选择年份和月份。年份范围为 2000—2100，可在 `config.js` 调整。
- 可查看某日已登记和空闲设备，并提交一件设备最多五个日期的预约；预约冲突以模拟服务端响应为准。
- 设备详情会展示服务端返回的类别、说明、累计次数、位置、型号、开放时段和设备状态；缺少字段会标明“服务端未提供”。
- 服务端未返回预约冲突后，页面会显示设备和日期的提交结果，并在当前浏览器保存最近的提交请求；日历会标记本机提交日期。
- 使用登记表区分日期、时段、预计时长、登记人、设备状态和沟通入口；接口未提供的信息不会用默认值冒充。
- 管理员工作台保留设备目录中的累计 `UseCount` 统计，并可切换“本月”“近 30 天”或自定义日期区间。区间统计根据每台设备的 `UseDate` 登记记录计算。
- 页面包含设备一览、使用说明和公告区块，导航会滚动到对应内容。
- 页面登录入口提供课程演示身份，用于展示使用者和管理员两种界面。
- 成功读取的服务端响应会缓存在浏览器。服务端不可达时可查看已有缓存，但页面进入只读状态，不提交预约。

## 本地运行

### 1. 启动课程模拟服务端

在 Windows 上解压课程提供的服务端文件，按课程说明运行 `模拟服务端.exe`。默认地址为 `http://127.0.0.1:12345`。保持服务端窗口开启，并按课程要求将 `Device.txt`、`Record.txt` 放在服务端程序指定的位置。

可以在浏览器访问以下地址检查服务端是否响应：

```text
http://127.0.0.1:12345/getDevices?page=1&pageSize=5
```

如果这个地址无法打开，先检查服务端程序和端口；如果地址能打开而页面仍显示离线，通常需要检查服务端是否允许网页来源的跨域请求。

### 2. 启动网页

在 Windows 终端进入项目文件夹后，运行 Python 自带的静态文件服务器：

```powershell
cd E:\Programs\campus-equipment-booking
py -m http.server 5500
```

保持终端窗口开启，在浏览器访问：

```text
http://127.0.0.1:5500
```

也可以使用其他静态 HTTP 服务器。直接双击 `index.html` 在部分浏览器中会受到本地文件跨域限制；使用本地 HTTP 地址更便于排查问题。

### 3. 设置服务端地址

项目默认连接 `http://127.0.0.1:12345`。如课程模拟服务端运行在其他地址，编辑 `config.js`：

```js
window.SITE_CONFIG = Object.freeze({
  apiBaseUrl: "http://127.0.0.1:12345",
  requestTimeoutMs: 8000,
  pageSize: 5,
  calendarMinYear: 2000,
  calendarMaxYear: 2100
});
```

`apiBaseUrl` 留空时，接口适配器会使用默认地址 `http://127.0.0.1:12345`。

## 演示账号与能力边界

| 身份 | 账号 | 密码 |
| --- | --- | --- |
| 使用者 | `student` | `demo123` |
| 管理员 | `admin` | `demo123` |

这两个账号仅由前端校验，用来演示不同页面入口；浏览器本地保存的演示会话不构成身份认证。课程模拟服务端没有登录、用户身份或角色权限接口，因此管理员入口并非安全边界，不能用于真实账号、真实权限或敏感数据。项目也无法按用户区分预约记录。

当前接口没有预约用途字段、撤销预约、审批流程或管理员写操作。设备状态只有在服务端目录返回相应字段时才能展示；管理员页面不提供本地伪造的故障/翻新编辑。公告内容是项目静态更新，不代表服务端实时故障通报。

预约提交记录仅保存在当前浏览器，便于回看刚提交的设备和日期，不是服务端确认的个人预约清单，也不会同步到其他设备。当前服务端没有时段、预计时长、借用者身份或站内聊天接口：页面将这些信息标为未提供，并显示沟通能力尚未接入的说明。要支持借用者协商，后端需提供预约用户标识、消息会话、消息读写及适当的隐私授权。

## 页面统计口径

- **累计**：直接读取设备目录的 `UseCount`，保持课程服务端的累计使用口径。
- **本月、近 30 天、自定义区间**：对已选择的设备逐台读取日期记录，并按 `UseDate` 落在所选区间内的记录数汇总。区间统计是预约/使用登记记录数，不代表服务端确认已完成的实际使用；课程接口没有完成状态字段。
- 选择设备支持跨页保留。可选择当前页、全部设备或清空选择。
- “暂无登记”只表示当前接口没有该日的预约记录，不等于设备故障检查合格，也不保证全天可借。

## 接口映射

| 页面功能 | 课程服务接口 | 前端处理 |
| --- | --- | --- |
| 设备目录与累计统计 | `GET /getDevices?page=1&pageSize=10000` | 读取 `No`、`Name`、`UseCount`；前端搜索、分页及累计统计 |
| 设备编号 | `GET /getDeviceNo` | 兼容服务端返回的 XML 字符串数组 |
| 日历与登记历史 | `GET /getRecordByNo?no=...&start=...&end=...` | 将 `UseDate` 转为日期；区间统计按记录日期过滤 |
| 当日已登记 | `GET /getRecordByDate?date=...&page=1&pageSize=10000` | 记录关联设备目录后分页显示 |
| 当日空闲设备 | 当日记录 + `/getDeviceNo` | 以设备编号集合扣除已有登记设备 |
| 提交预约 | `GET /regDevice?No=...&UseDates=日期,日期` | 显示服务端返回的冲突日期；不提交接口不支持的用途字段 |

日期范围统计在浏览器中对每台所选设备请求 `/getRecordByNo`，并依据 `UseDate` 计算，不会修改服务端记录。日期字段可能使用 .NET `/Date(milliseconds)/` 格式，适配器会转换后用于日历与统计。

## 主要文件

- `index.html`：登录入口、设备工作台、日历、管理员统计、使用说明和公告结构。
- `styles.css`：页面视觉样式与响应式布局。
- `app.js`：页面状态、渲染、日历与统计交互、前端演示身份。
- `api.js`：课程模拟服务端接口适配、日期格式转换和只读缓存。
- `config.js`：服务端地址、请求超时、列表页大小和日历年份范围。
- `assets/favicon.svg`：本地图标。

## 手动核对清单

1. 启动模拟服务端和网页，确认设备列表可加载，选择设备后日历与当日记录可显示。
2. 使用 `student / demo123` 登录，确认使用者工作台正常；退出后使用 `admin / demo123` 登录，确认管理员统计入口可用。
3. 在管理员页选择设备，依次核对累计、本月、近 30 天和自定义区间；检查统计卡片、图表标题和统计口径说明同步更新。
4. 在日历中用年月选择器跳转，并用箭头前后翻月；检查年份边界 2000 和 2100。
5. 测试设备详情、时间/状态缺失提示、预约提交结果与本机预约记录；测试沟通入口的接口说明。
6. 测试导航区块、预约冲突反馈，以及断开服务端后的缓存只读状态。

实际接口行为、跨域设置和预约冲突需要在运行课程提供的 Windows 服务端时核验。本项目不包含替代服务端的模拟数据。
