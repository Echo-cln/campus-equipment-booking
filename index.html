HOW IT WORKS

使用说明

从启动课程服务端到完成一次预约，按下面的顺序操作。

01—04
01

启动模拟服务端

先解压课程提供的服务端，在 Windows 上运行 模拟服务端.exe。保持程序窗口开启，确认 Device.txt 和 Record.txt 留在服务端要求的目录。

02

确认设备目录

页面显示“服务端在线”后，在设备一览中搜索名称或编号。点击设备可查看日历和使用记录。

03

选日期并提交预约

通过日历箭头或年月选择器定位日期，再点击“预约所选设备”。一次最多提交五个日期；冲突日期以服务端返回结果为准。

04

查看记录与统计

管理员演示账号可查看设备累计次数和选定日期范围内的登记记录。日期范围统计按记录的 UseDate 计算，不代表服务端确认的实际完成使用。

Windows 终端 · 静态页面
cd E:\Programs\campus-equipment-booking
py -m http.server 5500

浏览器访问 http://127.0.0.1:5500。若页面仍离线，检查服务端是否运行及浏览器跨域提示。

常见问题：接口地址能打开，页面却显示离线？

通常是网页来源与服务端端口不同导致跨域请求被浏览器拦截。先打开浏览器开发者工具的 Console 查看报错，再按课程环境要求配置服务端跨域，或使用老师指定的页面运行方式。
