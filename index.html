USER GUIDE

使用说明

按“找设备—看日期—提交预约—确认结果”的顺序完成借用。

01—05
01

登录并查找设备

使用已验证邮箱登录工作台，在“设备一览”按名称或编号搜索。点击“设备详情”查看管理员已登记的编号、类别、说明和状态。

02

查看日期登记

选中设备后，在日历选择日期。日历标记表示云端预约；无预约记录不代表设备已完成故障检查。

03

核对时段与设备状态

查看登记时段、预计时长和设备状态。只展示设备档案中实际登记的字段；提交预约前应向管理员确认可借时间及设备状况。

04

提交预约并跟进进度

选择日期后填写时段和用途。数据库负责检查日期和时段冲突，“我的预约”还会显示云端时段、处理状态和预约记录；两类信息会分别标明来源。

05

处理交接与使用协调

在“预约与设备服务”提交报修或候补登记。预约时允许其他用户联系后，可在私有会话里协商；预约变更仍由预约者提交。

网页打不开或显示离线时怎么处理？

检查 Supabase 项目 URL、publishable key、数据库 migration 和认证回调地址。正式站点使用 HTTPS；本地调试时可用 Python 静态服务器打开页面。
