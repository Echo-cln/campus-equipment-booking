USER GUIDE

使用说明

按“找设备—看日期—提交预约—确认结果”的顺序完成借用。

01—05
01

登录并查找设备

使用课程提供的演示身份进入工作台，在“设备一览”按名称或编号搜索。点击“设备详情”查看服务端提供的编号、类别、说明和状态。

02

查看日期登记

选中设备后，在日历选择日期。日历标记表示服务端记录；“暂无登记”仅代表当前接口没有返回该日记录，不保证设备无故障或全天可借。

03

核对时段与设备状态

查看登记时段、预计时长和设备状态。课程接口未提供的字段会明确标为“未提供”，提交预约前应向管理员确认可借时间及设备状况。

04

提交预约并看反馈

选择一件设备和最多五个日期，提交后根据服务端响应判断成功或冲突。成功提交的日期和设备会保存在本机“预约提交记录”中。

05

需要协调时联系管理员

当前系统没有借用者身份和站内消息接口，因此暂不能直接联系登记人或协商先后顺序。请通过课程指定渠道沟通。

网页打不开或显示离线时怎么处理？

先按项目 README 启动课程模拟服务端，再用本地 HTTP 服务器打开网页。若服务端地址能打开但页面仍离线，检查浏览器 Console 中的跨域错误，并按课程环境要求设置服务端来源权限。
